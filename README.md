# Developer Assistant OpenTelemetry — Core

PHP telemetry integration for Developer Intelligence Assistant. This package provides shared OpenTelemetry instrumentation used by the framework adapters.

## Installation

```sh
composer require aminmh/developer-assistant-otel-core
```

Requires PHP 8.1 or newer. Install a framework adapter for Laravel or Symfony, or integrate the core directly.

See the [installation and configuration guide](docs/installation.md) for optional OpenTelemetry extensions, export configuration, framework setup, and runtime behavior.
